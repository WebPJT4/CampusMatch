## 📖 프로젝트 소개 (Introduction)

대학 생활 중 수많은 공지사항과 프로그램이 쏟아지지만, 정작 나에게 필요한 정보를 찾기는 쉽지 않습니다.
**_"캠퍼스 매치"_**는 간단한 진단 테스트를 통해 학생을 **8가지 유형(제이, J)**으로 분류하고, 각 유형의 니즈에 딱 맞는 교내 프로그램과 대외활동을 추천해 주는 큐레이션 서비스입니다.

## 💻 페이지별 핵심 로직 (Core Logic & Architecture)

본 서비스는 별도의 백엔드 서버 없이 프론트엔드 기술만으로 데이터 흐름과 상태 관리를 완결성 있게 구현했습니다.

### 1. 진입 및 온보딩 (Landing & Intro)
* **세션 기반 사용자 식별**: `sessionStorage`를 활용하여 사용자의 이름을 브라우저 세션 동안 유지합니다. 이를 통해 DB 없이도 페이지 간 사용자 정보를 공유합니다.
* **예외 처리 및 리다이렉트**: 이름 데이터 없이 내부 페이지(`intro`, `question`)에 접근할 경우, 이를 감지하여 강제로 메인 화면으로 리다이렉트(Redirect) 시키는 '세션 가드(Session Guard)' 로직이 적용되었습니다.

### 2. 성향 진단 모듈 (Question)
* **무상태(Stateless) 아키텍처**: 새로고침 시 데이터 유실을 방지하기 위해, 현재 진행 상황(`q`)과 답변 데이터(`a`)를 **URL 쿼리 파라미터**로 관리합니다.
* **데이터 압축 알고리즘**: 15개의 답변(A/B)을 이진수(0/1)로 변환한 뒤, 이를 **Base36 문자열로 인코딩**하여 URL 길이를 최소화하고 공유 편의성을 높였습니다.
* **이미지 프리로딩 (Smart Preloading)**: 다음 문항의 이미지를 `Fetch Priority API`를 이용해 백그라운드에서 미리 로드함으로써, 문항 전환 시 렌더링 지연(LCP)을 제거했습니다.

### 3. 결과 분석 및 추천 (Result)
* **유형 도출 알고리즘**: 3가지 축(목표, 관심, 환경)의 답변 데이터를 집계하여 다수결 로직으로 최종 유형(예: `ODS`)을 산출하고, 사전에 정의된 페르소나 데이터와 매핑합니다.
* **실시간 데이터 가공**: 추천 프로그램의 마감일(`deadline`) 데이터를 기반으로 **D-Day를 실시간으로 계산**하여 배지로 표시하며, 마감된 공지는 자동으로 필터링하거나 시각적으로 구분합니다.
* **고해상도 이미지 저장 (Ghost Clone 기법)**: 결과 화면을 이미지로 저장할 때, 화면 밖(`off-screen`)에 원본 DOM을 복제(Clone)하여 렌더링한 후 캡처하는 방식을 사용하여, 모바일 해상도나 스크롤 여부에 관계없이 깨끗한 결과 이미지를 생성합니다.

## 🧠 성향 분석 알고리즘 (Algorithm)

본 서비스는 학생의 성향을 **3가지 핵심 지표**를 기준으로 분류합니다.

### 1. 목표 지향 (Goal Direction)
_무엇을 위해 프로그램을 탐색하는가?_
| 구분 | 설명 | 관련 키워드 |
|:---:|:---|:---|
| **O (Outcome)**<br>성과 중심 | 취업 스펙, 장학금, 수상 등 명확하고 **가시적인 결과물**을 중요시합니다. | 인턴, 자격증, 공모전, 장학금 |
| **P (Process)**<br>성장 중심 | 지적 호기심, 개인적 성장, 정서적 만족 등 **과정과 내적 동기**를 중요시합니다. | 학업 심화, 취미, 봉사, 멘토링 |

### 2. 관심 범위 (Interest Scope)
_어떤 분야의 프로그램을 탐색하는가?_
| 구분 | 설명 | 관련 키워드 |
|:---:|:---|:---|
| **D (Deep)**<br>전공 심화 | 자신의 **전공**이나 특정 전문 분야에 대한 깊이 있는 학습을 선호합니다. | 랩 인턴, 캡스톤, 전공 자격증 |
| **W (Wide)**<br>경험 확장 | 전공에 국한되지 않고 **폭넓은 분야**의 새로운 경험을 선호합니다. | 교양, 예술, 대외활동, 여행 |

### 3. 선호 환경 (Preferred Environment)
_어떤 환경에서 활동하는 것을 선호하는가?_
| 구분 | 설명 | 관련 키워드 |
|:---:|:---|:---|
| **S (Social)**<br>관계 지향 | **타인과의 교류와 협업**을 통해 시너지를 내는 것을 선호합니다. | 팀 프로젝트, 동아리, 학생회 |
| **I (Individual)**<br>개인 지향 | **독립적으로 몰입**하고 개인의 역량을 쌓는 활동을 선호합니다. | 1인 연구, 독학, 개인 운동 |

## 🧬 8가지 학생 유형 (The 8 Personas)

위 3가지 지표의 조합을 통해 도출된 **8명의 '제이(J)'** 유형입니다.

| 유형 코드 | 유형 명칭 | 별칭 (Character Name) | 한줄 요약 |
|:---:|:---|:---|:---|
| **ODS** | 전공 스펙을 주도하는 엘리트 리더 | **🔥 열정 리더 제이** | 팀을 이끌며 전공 성과를 만들어내는 리더 |
| **ODI** | 홀로 전공을 파고드는 스페셜리스트 | **🧐 고독한 천재 제이** | 깊이 있는 전문성을 홀로 쌓아가는 연구자 |
| **OWS** | 스펙과 인맥을 모두 잡는 만능 네트워커 | **🚌 A+ 버스기사 제이** | 다양한 경험과 인맥을 모두 섭렵하는 마당발 |
| **OWI** | 실속을 개척하는 독립적 도전자 | **🏆 올라운더 갓생 제이** | 혼자서도 다양한 스펙을 척척 해내는 능력자 |
| **PDS** | 함께 탐구하는 전공 심화 학자 | **✨ 다재다능 슈퍼 제이** | 동료와 함께 학문의 즐거움을 탐구하는 학구파 |
| **PDI** | 홀로 깊이 파고드는 순수 탐구자 | **📚 걸어다니는 사전 제이** | 묵묵히 자신만의 학문적 세계를 구축하는 탐구자 |
| **PWS** | 경험과 관계를 통해 성장하는 탐험가 | **🎉 마당발 핵인싸 제이** | 사람들과 어울리며 다채로운 추억을 쌓는 모험가 |
| **PWI** | 나만의 템포로 성장하는 웰빙 러너 | **👼 평화추구 천사 제이** | 소소한 행복과 개인의 성장을 중시하는 힐러 |

## 🛠️ 기술 스택 (Tech Stack)

* **Frontend**: HTML5, CSS3, JavaScript
* **Backend**: 미 구현 (추후, DB 연결과 함께 개발 예정)
* **Database**: 미 구현 (현재는 초기 테스트단계로 필요한 전달 변수들은 URL Parameter와 SessionStorage를 활용함)
* **Deployment**: Localhost (Live Server)
